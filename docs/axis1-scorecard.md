# 축1 채점표 — 전달 경로 마찰 (H1 kill switch 계측 도구)

> H1(대체재 대비 마찰 감소)의 상위 게이트. "탭 수"만이 아니라 **로그인/광고/설치 무게**를 함께 채점한다.
> 개발자측 측정가능분은 Phase 1에서 채우고, 카톡/실기기분은 [user-intervention.md](user-intervention.md) UI-2로 인계한다.

## A. 개발자측 측정 가능분 (Phase 1에서 계측 — 2026-07-21 측정)
| 항목 | 측정 방법 | 우리 뷰어 | 기준 |
|---|---|---|---|
| 인앱 파일피커 탭 수 (앱 열림→문서 표시) | 수기 카운트 | **2탭** ("파일 선택" → OS 피커에서 파일 지정) | 낮을수록 우위 |
| 초기 셸 크기 (설치 무게, gzip) | 빌드 리포트 | **≈5.7KB gzip** (index.html+shell js+css+manifest+icon = 12.2KB raw) | 경량 목표 ✅ |
| 온디맨드 렌더러 (설치 무게 아님) | 빌드 리포트 | PDF 98KB / DOCX 144KB / pdf worker 403KB gzip — 첫 열람 시에만 로드(코드 스플리팅) | 초기 셸에 미포함 |
| 로그인 노출 | 설계 검증 + egress-0 E2E | **0회** (계정 개념 없음, 순수 클라이언트) | 0 필수 ✅ |
| 광고 노출 | 설계 검증 | **0회** (광고 SDK/네트워크 없음) | 0 필수 ✅ |
| 문서 외부 유출 | egress-0 E2E (교차 출처 요청 0건) | **0건** (기기를 떠나지 않음) | 0 필수 ✅ |

## Kill switch 판정
- B의 경로A 탭 수가 한컴 대비 **−1 이상** AND 로그인/광고 **0회** AND 설치 무게 우위 → **H1 유지**.
- 하나라도 미충족 → **H1 기각 → 재심사**([business-risk.md](business-risk.md)).
- 실기기 데이터 미확보 시 → H1 **UNVERIFIED**(Phase 1은 A + 프로토콜 인계까지만으로 DoD 충족).
